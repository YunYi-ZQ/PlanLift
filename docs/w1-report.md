## 三、测试中发现并修复的 2 个真实缺陷

| # | 问题 | 现象 | 修复 |
|---|---|---|---|
| 1 | 重量输入框预填 `0` 且光标在首位 | 输入 `60` 得到 `600` | 改用 `TextFieldValue` 打开时全选原值，输入即替换 |
| 2 | 第二组重量不继承 | 同动作第二组重新从 0 kg 开始，训练中要反复输入 | 完成后把重量/次数复制给同动作下一组未填写的行 |

## 六、当前限制（W2 解决）

1. **没有自动加重**：组数与次数来自模板，不会因为你完成得好而加重量 → W2 加重引擎。
2. **周次按自然日推进**：7 天自动 +1 周，而不是按训练次数 → W2 改为按完成次数推进。
3. **没有组数看板**：无法看到每周每肌群组数 → W2。
4. **无提醒**：训练日不会通知 → W3。
5. **无同步**：数据只在本机 → W4。
