# W2 交付报告（计划引擎）

> 版本：v0.3.0　｜　日期：2026-11-03

## 一、本期交付

| 模块 | 内容 |
|---|---|
| **加重引擎** | 双重递进 + RIR：全部组达到次数上限且仍有余力 → 加一档；低于下限 → 降半档；中间态 → 重量不变、目标 +1 次 |
| **档位规则** | 下肢 5 kg（女 2.5）／上肢 2.5 kg（女 1.25）／器械与绳索 2.5 kg |
| **训练页** | 每个动作显示「上次 60×8, 60×8, 60×8」与「加 5 kg 到 65 kg」的原因，重量自动预填 |
| **周次推进** | 由自然日改为「完成次数 / 每周天数」，漏练不会被跳周 |
| **每周组数看板** | 按肌群统计近 7 天正式组，对标 10–20 组区间（不足橙色、超标红色） |
| **e1RM** | Epley 公式，按动作取历史最好一组，列出最好成绩 |

[PASS] 次日：「#1 · 5-5 · RIR 2 · 上次 60×8, 60×8, 60×8」
[PASS] 次日：建议 65 kg
[PASS] 原因：「全部组达到 5 次且 RIR 2：加 5 kg 到 65 kg，次数回到 5」
